# Outfitter

Modernization of the Vanilla WoW 1.12.1 Outfitter addon, based on
[CosminPOP/Outfitter](https://github.com/CosminPOP/Outfitter).

Targets WoW 1.12.1 with brues-code/ClassicAPI and clean coexistence with
brues-code/pfUI while preserving Outfitter's outfit model, automatic outfits,
layering/priority semantics, keybinds, and compatible SavedVariables.

Active development is on the `dev` branch. See `DEV_PROGRESS.md` and
`MODERNIZATION.md`.
